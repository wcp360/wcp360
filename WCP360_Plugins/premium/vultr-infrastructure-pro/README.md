# Vultr infrastructure connector

This is an optional premium connector proposal, not an implemented or installable package. Its current state is **design**, **not installable**, with the source distribution model **undecided**.

Prepare bounded infrastructure inventory and reviewed provisioning for a selected Vultr account.

## Core boundary

An external account token is not a Core entitlement or permission to rebuild, destroy or import a node. This is a design-only connector proposal. Essential hosting, current actor and tenant authorization, native service drivers and recovery remain in the free Core. No production interface, publisher trust, installation or effectful capability is established by this metadata.

## Intended scope and evidence

1. Bind account, resource identifiers and location/capability choices to the current authorized plan.
2. Refuse unmanaged resource rebuild/delete operations and preserve ownership across credential changes.
3. Exercise delayed provider responses, duplicate requests and retained-data recovery after a failed rebuild.

The complete [acceptance record](docs/ACCEPTANCE.md) defines evidence still required. No checks are marked complete, and no SDK/provider version, target compatibility, release artifact or production entitlement is selected.
