## Identity, source and policy findings

- Pydio, Gallery, iTron Clock and Mailserver use QUALIFIER. Their project/edition/method must be resolved before offering installation. iTron Clock has a reinforced-review qualification rather than À IDENTIFIER.
- Drupal Core/Drupal CMS and Pydio/Pydio Cells need edition/dependency decisions; do not merge them merely because names are related.
- WooCommerce, pgvector and PostGIS extend an existing parent. Smarty and SimplePie are project dependencies. Frameworks/templates/build tools need project workflows rather than independent application installation.
- The three CLUSTER references, two private LAB references and Windows VM require distinct placement, authority and failure/recovery models.
- Source access labels describe intended audiences. USER, ADMIN-DELEGABLE or ISOLE cannot become a Core permission or a privileged execution grant.

Of the 56 populated source cells, 28 point to Coolify's service overview and 3 to Installatron's application table. Other rows also use discovery catalogues or generic pages. The column title Source vérifiée is retained from the source; this inspection did not independently verify those upstream pages, maintenance, versions, licensing or release artifacts. The remaining 354 rows have no populated cell in that column.
