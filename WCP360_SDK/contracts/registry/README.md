# Vendor Registry candidate

The vendor site's read-only Registry has a separate candidate contract at version 0.1.0. Consumer copies and source fingerprints live beside the independent [PHP client](../../php/registry-client/README.md), under `contracts/PROVENANCE.json`.

This boundary covers public editorial package/release metadata and compatibility queries only. It is neither the Core API nor a production extension manifest, distribution authorization or installer. Accepted Core specifications retain their existing authority.
