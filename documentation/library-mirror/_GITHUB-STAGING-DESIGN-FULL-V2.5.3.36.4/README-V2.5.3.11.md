# WCP360 V2.5.3.11 — Style Restored + Color Corrected

This version intentionally restores **V2.5.3.9 as the visual base**.

Only the following are changed:
- Light/Dark palette tuning
- text/background contrast
- semantic status colors
- active/focus colors
- removal of accidental over-saturation

Not changed:
- layout
- sidebar structure
- header structure
- spacing
- card geometry
- border radius
- shadow character
- overall visual style

V2.5.3.10 should be considered superseded for visual direction.
