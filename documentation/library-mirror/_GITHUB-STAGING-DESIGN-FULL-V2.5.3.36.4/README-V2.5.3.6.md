# WCP360 V2.5.3.6 — UX Shell & General Visual Refinement

## Main changes

- Sidebar reduced from broad demo navigation to contextual operating navigation.
- Separate WCP-USER and WCP-ADMIN information architecture.
- Application Workspace gets its own contextual sidebar.
- Global header simplified.
- Search becomes visually central.
- Shell width and page gutter standardized.
- Reduced visual noise, borders, glows and badge decoration.
- Stronger typography hierarchy.
- Cleaner Health / Dashboard bands.
- More mature tables and operational surfaces.
- Action Center visually isolated.
- Light/Dark/System parity retained.
- SPECIAL MENU removed from canonical screens to avoid prototype noise.

## Design principle

WCP360 should feel like a calm operations cockpit:
context → health → action → activity.

Not a catalog of hosting tools.
