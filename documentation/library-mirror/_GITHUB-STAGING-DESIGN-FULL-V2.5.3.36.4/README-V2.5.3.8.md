# WCP360 V2.5.3.8 — Shell Frame Separation Refinement

## Goal
Create a much more elegant visual separation between the shell layers: frame, header, sidebar, workspace and bottom operations area.

## What changed
- Floating framed shell with visible gaps between regions.
- Rounded, elevated Context Rail and Workspace Sidebar.
- Header treated like its own framed bar instead of a flat strip.
- Main workspace wrapped inside a clearly separated cockpit panel.
- Better section separators for cards, surface headers and lists.
- Stronger visual structure without adding clutter.
- Preserved Light / Dark / System theme support.

## Expected result
The interface should feel less like one large flat page and more like a high-end product cockpit made of clearly separated operational zones.
