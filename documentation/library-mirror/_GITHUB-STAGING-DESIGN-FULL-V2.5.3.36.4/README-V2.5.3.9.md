# WCP360 V2.5.3.9 — Reference Unified UI

## New visual baseline
The supplied dashboard design is now the primary visual reference for WCP360.

## Adopted
- Single clean sidebar with collapse behavior
- Horizontal header
- Central search
- User actions at right
- Rounded main content frame
- Neutral cards with thin borders
- Clean light/dark themes
- Responsive mobile sidebar
- Inter typography

## Adapted for WCP360
- Purple replaced by WCP360 blue/cyan identity
- Generic project-management navigation replaced by WCP-USER/WCP-ADMIN architecture
- Application-centric hosting resources
- Security / jobs / servers / DNS / backups / monitoring
- Action Center and operational states

## Scope
All HTML pages load `assets/reference-ui.css`, which provides a compatibility layer so legacy prototype screens visually converge toward this new baseline. Six canonical screens are fully rebuilt in the new structure.
