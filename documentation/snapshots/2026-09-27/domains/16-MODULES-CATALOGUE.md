# WCP360 — Modules Catalogue Requirements

## Current consolidated status

Earlier H2 work produced approximately 33 active candidate modules plus deferred items, but the module catalogue is not yet demonstrated implementation-ready.

## Required module fiche

Every significant module must contain:
- MODULE ID;
- NAME;
- PURPOSE;
- STATUS;
- DEPENDENCIES;
- WCP-USER;
- WCP-ADMIN;
- ROLES;
- PERMISSIONS;
- ENTITLEMENTS;
- DATABASE;
- API;
- IPC;
- SYSTEM ACTIONS;
- UI;
- JOBS;
- EVENTS;
- SECURITY;
- AUDIT;
- LOGGING;
- FAILURE MODES;
- ROLLBACK;
- TESTS;
- DOCUMENTATION.

## Rule

A module being named/candidate does not mean its contract is fully populated.

The consolidated module registry must align with typed identifiers, data entities, authorization, audit and tests before implementation readiness.
