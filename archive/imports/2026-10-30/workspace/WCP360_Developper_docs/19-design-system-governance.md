# 19 --- Gouvernance du Design System

## Workflow

Proposition → revue UX → revue accessibilité → revue sécurité si
sensible → implémentation → tests → documentation → Stable.

## Ownership

Chaque composant a un owner et un statut de maturité.

## Breaking changes

Une modification incompatible exige note de migration et version majeure
du composant ou du Design System.

## Contribution

Avant de créer un composant : vérifier primitives, composition possible,
cas existants WCP-USER/WCP-ADMIN et besoin réel de réutilisation.

## Documentation minimale

But, anatomie, variantes, états, responsive, clavier, accessibilité,
i18n/RTL, sécurité, exemples, anti-patterns, critères d'acceptation.
