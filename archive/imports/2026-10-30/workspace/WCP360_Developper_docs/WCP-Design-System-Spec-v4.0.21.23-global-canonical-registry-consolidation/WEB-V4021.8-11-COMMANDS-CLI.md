# V4.0.21.8 --- Web Stack CLI Mapping

Examples of safe surface mappings:

`wcpctl domain add --account <id> --name <fqdn>`
`wcpctl site create --account <id> --domain <id>`
`wcpctl webserver validate --site <id>`
`wcpctl webserver reconcile --site <id>`
`wcpctl php version-set --site <id> --runtime <id> --dry-run`
`wcpctl php pool-restart --site <id>` `wcpctl tls issue --site <id>`
`wcpctl dns record-create --zone <id> --type A ...`
`wcpctl dnssec enable --zone <id> --dry-run`

The CLI never accepts `--nginx-conf`, `--apache-conf`, `--php-ini-raw`,
`--shell`, arbitrary service units or arbitrary privileged filesystem
paths. Advanced directives use typed/allowlisted schemas.
