# V4.0.21.15 --- Documentation Governance & Anti-duplication

## Objectif

Empêcher les 1300+ documents de redevenir contradictoires.

## Règles

Un concept = une source canonique. Les autres documents référencent au
lieu de redéfinir. Tout nouveau fichier déclare famille, statut, version
effective et relations de supersession. Les snapshots/audits sont
immuables historiquement.

## Gate

Un conflit sémantique entre deux sources canoniques est P0 documentaire.
