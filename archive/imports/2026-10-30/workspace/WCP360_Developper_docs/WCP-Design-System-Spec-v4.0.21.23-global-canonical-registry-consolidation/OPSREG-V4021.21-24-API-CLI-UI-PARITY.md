# V4.0.21.21 --- Operations API / CLI / UI Parity

WCP-ADMIN, permitted WCP-USER surfaces, REST and CLI use canonical
Operation IDs. High-risk restore/firewall/update/recovery actions expose
impact, step-up and Job state consistently.

synthesize READY from client-side assumptions. CLI recovery commands
remain policy/audit controlled and do not become an undocumented
