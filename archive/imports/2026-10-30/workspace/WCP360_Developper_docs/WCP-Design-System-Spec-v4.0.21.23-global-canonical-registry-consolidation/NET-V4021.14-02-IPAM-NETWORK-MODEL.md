# V4.0.21.14 --- IPAM / Network Resource Model

## Ressources

`network_interface`, `ip_address`, `ip_pool`, `ip_assignment`,
`ip_range`, `route_ref`, `nat_mapping`, `reserved_ip`,
`service_ip_binding`.

## Types

IPv4/IPv6, primary/shared/dedicated/reserved/service/outbound-mail. Une
IP connaît interface, prefix/subnet, routability, NAT public mapping,
allocation state, account/domain/service bindings.

## Opérations

discover, add/remove where host policy allows, reserve/unreserve,
assign/release, validate routability, migrate, rebuild pool, IPv6 range
management.

## Safety

Une IP utilisée ne peut être supprimée. Les migrations produisent impact
graph, DNS/TLS/web/mail dependency plan, staged changes, verification et
rollback plan.
