# V4.0.21.11 --- Operations / Security / Installer P0 Failure Matrix

## Backup/restore

corrupt artifact rejected; wrong encryption key fails safely; remote
target unavailable does not mark success; cross-tenant restore denied;
restore conflict requires decision; verified backup actually
read/checked.

## Malware/security

scanner unavailable visible; stale signatures visible; quarantine
reversible per policy; firewall change cannot lock out management
silently; WAF bad rules rollback; automated ban expiry works.

## Monitoring/logs

monitor outage does not report healthy; stale observation
distinguishable; secret redaction tested; alert storm deduplicated;
tenant log leakage denied.

## Updates

failed service update triggers recovery path; schema/binary
compatibility checked; reboot requirement surfaced; interrupted update
resumable/reconcilable.

## Installer

unsupported OS blocked; insufficient disk blocked; package-manager lock
handled; existing conflicting services detected; power loss resumes
safely; bootstrap token invalid after finalization; `READY` impossible
while mandatory P0 check fails.
