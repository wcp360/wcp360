# V4.0.21.19 --- Archive / Mailing Lists / Optional Groupware

Mail archive/journaling is adapter-backed with retention, encryption,
access control, export and immutable-target capability where available.

Mailing lists have owner/domain, members, moderators, posting policy,
bounce/ rate controls and abuse protection.

CalDAV/CardDAV/calendar/contact remains an optional entitlement/module
with independent privacy/storage/backup contracts; it is not required
for core mail readiness.
