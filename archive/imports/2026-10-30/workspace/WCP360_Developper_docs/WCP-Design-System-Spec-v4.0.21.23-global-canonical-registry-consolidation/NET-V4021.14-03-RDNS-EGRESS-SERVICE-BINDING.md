# V4.0.21.14 --- rDNS / Egress / Service IP Binding

## Modèle

WCP distingue adresse d'écoute, adresse source sortante, adresse publiée
DNS, NAT mapping et PTR/rDNS provider capability.

## Mail

L'outbound mail IP peut être assignée par host/profile/domain selon
policy. PTR, HELO/EHLO, forward-confirmed reverse DNS, SPF and
reputation diagnostics sont corrélés sans prétendre gérer un PTR si le
fournisseur ne l'autorise pas.

## Capability

`RDNS_READ`, `RDNS_WRITE`, `SOURCE_IP_BINDING`, `NAT_DISCOVERY`,
`DEDICATED_IP_ASSIGNMENT`.
