# V4.0.21.8 --- DNS / DNSSEC Resource Dictionaries

## `dns_zone`

`id`, `account_id`, `zone_name`, `zone_type`, `serial_policy`, `status`,
`provider_backend_id`, `desired_revision`, `observed_revision?`,
`version`.

## `dns_record`

`id`, `zone_id`, `owner_name`, `record_type`, `ttl`, `rdata_typed`,
`priority?`, `weight?`, `port?`, `status`, `version`.

## `dnssec_keyset`

`id`, `zone_id`, `algorithm`, `ksk_ref`, `zsk_ref`, `ds_material`,
`rollover_state`, `status`, `version`.

## `dns_observation`

`zone_id`, `authoritative_serial`, `nameserver_observations`,
`dnssec_validation_state`, `observed_at`, `drift_state`.

## Rules

Record data is typed per RR type. Zone writes are atomic/revisioned.
DNSSEC private material is never returned as plaintext.
Enable/disable/rollover has an explicit parent-DS coordination state;
WCP never claims DNSSEC healthy solely because local signing is enabled.
