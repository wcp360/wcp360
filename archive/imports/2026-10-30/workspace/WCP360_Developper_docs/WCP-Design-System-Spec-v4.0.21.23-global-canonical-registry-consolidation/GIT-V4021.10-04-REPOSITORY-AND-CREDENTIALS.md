# V4.0.21.10 --- Git Repository, Deploy Keys & Credential Contract

## `git_repository`

account/site ownership, provider-independent remote metadata, branch/ref
policy, deploy path reference, status and observed revision.

## Credentials

Deploy keys, PAT/app tokens and webhook secrets sont SecretStore-backed.
Le secret brut n'est pas récupérable après création/import. Les URLs
contenant des credentials sont rejetées ou nettoyées.

## Host verification

SSH known-host identity est pin/verified selon policy ;
`StrictHostKeyChecking=no` n'est pas une option WCP-USER.

## Operations

clone/fetch/checkout/deploy-key-rotate/webhook-create/webhook-rotate/reconcile.
Aucune opération publique `git <arbitrary args>`.
