# V4.0.21.8 --- Web / PHP / TLS / DNS P0 Acceptance Matrix

## P0

-   account A cannot bind domain/site/config belonging to B;
-   duplicate canonical FQDN is rejected according to ownership policy;
-   document root cannot escape managed account root;
-   custom directive cannot inject include/path/command outside allowed
    schema;
-   invalid Nginx/Apache config never replaces active config;
-   reload failure rolls back and verifies previous revision;
-   PHP pool runs as expected managed identity and cgroup;
-   PHP socket is not cross-tenant accessible;
-   uninstalled/unsupported PHP runtime cannot be selected;
-   dangerous INI override cannot weaken security floor;
-   certificate private key is never returned/logged;
-   mismatched certificate/key cannot activate;
-   failed renewal preserves valid active certificate;
-   DNS record validation is RR-type aware;
-   DNS update cannot cross zone/account scope;
-   DNSSEC private keys are non-exportable through normal surfaces;
-   DNSSEC UI does not claim healthy until authoritative/validation
    evidence exists;
-   drift in webserver/PHP/DNS desired vs observed state is detectable;
-   UI/API/CLI produce the same policy decision and Operation ID.
