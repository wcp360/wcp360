# V4.0.21.12 --- Remaining Decision Classes

## Décisions qui doivent rester explicites jusqu'au choix final

-   distributions/versions Linux officiellement supportées;
-   backend firewall principal par host profile;
-   authoritative DNS backends certifiés;
-   mail stack(s) certifiées;
-   backup/object-storage adapters certifiés;
-   WAF/scanner commercial optionnel;
-   package/runtime support windows;
-   exact filesystem/quota backend matrix;
-   HA/multi-node scope for first stable release;
-   billing connectors shipped vs external;
-   telemetry defaults and retention defaults.

Ces choix sont des **product/platform decisions**, pas des trous à
masquer par une valeur arbitraire dans la documentation.
