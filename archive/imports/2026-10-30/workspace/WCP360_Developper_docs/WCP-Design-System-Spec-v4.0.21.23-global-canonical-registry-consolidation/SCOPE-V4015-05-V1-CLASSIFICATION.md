# V4.0.15 --- V1 Capability Classification

## CORE V1

WCP-ADMIN/WCP-USER, identity/RBAC/MFA/audit,
users/resellers/plans/quotas, domains/sites, Nginx baseline, PHP-FPM
multi-version, SSL/ACME, DNS baseline, MariaDB/MySQL baseline,
files/SFTP/FTP policy, cron, mail baseline with
Postfix/Dovecot/Rspamd/DKIM/SPF/DMARC, backups/restores, security
center/firewall/brute-force/malware integration,
API/jobs/events/webhooks, monitoring/health,
installer/preflight/setup/finalization/repair/rescue, update lifecycle
and single-node production profile.

## OPTIONAL V1 modules

Apache compatibility, PostgreSQL, Redis/Memcached, WordPress Toolkit,
Git deployments, Node.js/Python apps, external DNS providers, external
backup providers, webmail SSO, billing adapters, transfer adapters and
white-label/reseller extensions.

## ADVANCED / V1.x

Multi-node scheduling, automated HA/failover, distributed storage
adapters, advanced DB HA, advanced mail reputation automation, canary
cluster upgrades and richer CI/CD.

## EXPERIMENTAL

OpenLiteSpeed/LiteSpeed where certification is incomplete, Ruby/Go app
manager, emerging provider adapters and capabilities without stable
compatibility matrix.

## FUTURE

Full FinOps/chargeback, integrated commercial helpdesk, broad
marketplace/ecosystem, advanced fleet/hardware management and
nonessential enterprise governance extensions.

## EXTERNAL/INTEGRATION

WHMCS/Blesta/HostBill/FOSSBilling, public status providers,
chat/notification providers, cloud provider infrastructure and
third-party observability backends remain integrations behind contracts.
