# 851 --- Migration Adapter & Workflow

## Statut

**CANONICAL --- IMPLEMENTATION CONTRACT --- V3.7 Phase 3**

Ce document complète les contrats existants. Les règles de sécurité
`650–669` et les contrats systèmes `700–795` restent normatifs.

Discover → inventory → map → preflight/quota/conflicts → transfer →
transform → validate → incremental sync if supported → cutover →
post-check → close. Chaque source adapter expose capabilities ; les
éléments non migrables sont explicitement signalés, jamais ignorés.
