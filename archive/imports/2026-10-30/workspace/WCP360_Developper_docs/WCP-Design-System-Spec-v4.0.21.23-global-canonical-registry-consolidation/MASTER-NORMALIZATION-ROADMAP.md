# MASTER NORMALIZATION ROADMAP

## Phase A --- effectuée

Rapports historiques classés ; premiers chevauchements
Backup/SSH/Telemetry normalisés ; control plane proposé ; décisions
ouvertes listées.

## Phase B --- cette passe

Ajout des contrats transversaux manquants : ADR, version/support,
packages/repos, resource state, API implementation, trust boundaries,
failure/recovery.

## Phase C --- suivante

Pour chaque famille, marquer chaque document
`CANONICAL/OVERVIEW/SUBSPEC/ADAPTER/HISTORICAL/PROPOSAL`, puis supprimer
les contradictions normatives par référence au canonique.

## Phase D

Créer les contrats d'implémentation P0 : ressources, schémas API,
permissions, jobs, events, audit, erreurs, acceptance criteria.

## Phase E

Fermer les ADR prioritaires et promouvoir les domaines de `PARTIAL` à
`READY`.
