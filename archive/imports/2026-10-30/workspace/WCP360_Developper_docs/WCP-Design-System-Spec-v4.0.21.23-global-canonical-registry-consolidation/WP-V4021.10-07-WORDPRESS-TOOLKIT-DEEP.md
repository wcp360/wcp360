# V4.0.21.10 --- WordPress Toolkit Deep Contract

## Fonctions

discover/import/install, core/plugin/theme inventory, update planning,
update execution, maintenance mode, hardening, vulnerability findings,
clone, staging, sync sélectif, backup-before-change, health.

## Staging / clone

Le clone crée de nouvelles identities/resources lorsque nécessaire : DB,
credentials, salts, URLs, cache namespace, mail policy. Search/replace
est aware des données sérialisées. Les emails sortants d'un staging sont
désactivés ou redirigés selon policy pour éviter des envois réels.

## Updates

Plan → compatibility/preflight → backup checkpoint → maintenance policy
→ update → DB migrations → cache flush → health → rollback/escalation.

## Plugins vulnérables

Le système peut recommander, bloquer installation ou mettre en
quarantaine selon severity/policy, mais la quarantaine est un état
explicite et audité, pas une suppression silencieuse.

## Hardening

Security keys/salts, file editing policy, XML-RPC/application passwords
policy, permissions, debug exposure, version exposure et admin
protections sont des controls versionnés.
