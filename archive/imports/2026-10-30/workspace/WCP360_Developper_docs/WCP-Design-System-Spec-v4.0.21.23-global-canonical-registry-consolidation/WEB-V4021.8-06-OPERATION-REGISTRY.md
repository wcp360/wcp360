# V4.0.21.8 --- Exact Web / Webserver Operation Registry

## Web/domain

`DOMAIN-LIST`, `DOMAIN-READ`, `DOMAIN-ADD`, `DOMAIN-UPDATE`,
`DOMAIN-REMOVE`, `DOMAIN-VERIFY`, `SITE-LIST`, `SITE-READ`,
`SITE-CREATE`, `SITE-UPDATE`, `SITE-SUSPEND`, `SITE-RESUME`,
`SITE-DELETE-REQUEST`, `SITE-RECONCILE`, `DOMAIN-BIND`, `DOMAIN-UNBIND`,
`REDIRECT-SET`, `REDIRECT-REMOVE`.

## Webserver

`WEBSERVER-PROFILE-LIST`, `WEBSERVER-PROFILE-ASSIGN`,
`WEBSERVER-CONFIG-RENDER`, `WEBSERVER-CONFIG-VALIDATE`,
`WEBSERVER-CONFIG-APPLY`, `WEBSERVER-RELOAD`, `WEBSERVER-RECONCILE`,
`WEBSERVER-DRIFT-READ`, `WEBSERVER-CUSTOM-DIRECTIVES-VALIDATE`,
`WEBSERVER-CUSTOM-DIRECTIVES-APPLY`,
`WEBSERVER-CUSTOM-DIRECTIVES-RESET`.

Every mutation has exact capability/scope, audit action and either a Job
or explicit NO_JOB. Render/validate may be control-plane only;
apply/reload/reconcile are Job-backed privileged operations.
