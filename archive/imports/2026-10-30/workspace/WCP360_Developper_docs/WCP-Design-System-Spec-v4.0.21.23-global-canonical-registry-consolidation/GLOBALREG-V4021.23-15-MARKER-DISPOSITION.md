# V4.0.21.23 --- Marker Disposition Rules

Literal words `partial`, `todo`, `tbd` are not sufficient evidence of an
open specification gap.

Every explicit normative historical marker receives one disposition:
`CLOSED_BY:<doc>`, `SUPERSEDED_BY:<doc>`, `OUT_OF_SCOPE_V1:<reason>`,
`DEFERRED_NON_BLOCKING:<reason>` or `STILL_OPEN:<blocking requirement>`.

The twelve V4.0.18 `## PARTIAL` audits are superseded only when the
corresponding global registry/ledger in V4.0.21.23 contains the required
contract category. This version establishes those authorities;
exhaustive row-level population remains the final completeness gate.
