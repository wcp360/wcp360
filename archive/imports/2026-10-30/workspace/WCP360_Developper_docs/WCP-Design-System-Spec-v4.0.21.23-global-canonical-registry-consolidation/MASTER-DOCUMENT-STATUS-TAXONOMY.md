# MASTER DOCUMENT STATUS TAXONOMY

## Statuts documentaires

-   **CANONICAL** : source de vérité du sujet.
-   **OVERVIEW** : navigation et synthèse ; ne redéfinit pas le contrat
    canonique.
-   **SUBSPEC** : détail d'un sous-domaine.
-   **ADAPTER** : comportement spécifique à une technologie.
-   **HISTORICAL** : journal de version/audit ; non normatif.
-   **PROPOSAL** : architecture à valider.
-   **DEPRECATED** : conservé pour migration, ne doit plus recevoir de
    nouvelles exigences.
