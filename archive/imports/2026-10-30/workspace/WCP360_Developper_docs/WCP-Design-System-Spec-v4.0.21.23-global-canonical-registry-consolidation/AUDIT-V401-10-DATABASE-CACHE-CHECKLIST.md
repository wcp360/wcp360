# V4.0.1 --- Database Cache Checklist

MariaDB/MySQL et PostgreSQL : lifecycle, users, DB, grants,
charset/collation, connection limits, backup/restore, import/export,
upgrades, health, slow logs, credential rotation. Redis/Memcached :
tenant/app ownership, socket/port exposure, ACL/password,
memory/eviction, persistence, restart, namespace et isolation.
