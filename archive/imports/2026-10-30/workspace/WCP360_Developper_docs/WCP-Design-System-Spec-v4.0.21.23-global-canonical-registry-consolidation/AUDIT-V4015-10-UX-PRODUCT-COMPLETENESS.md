# V4.0.15 --- UX & Product Completeness Gate

## WCP-USER

Contextual app-centric navigation, global search/launcher,
domains/sites, mail, DB, files, backups, security, usage, developer
tooling, reseller context and responsive/accessibility requirements.

## WCP-ADMIN

Infrastructure/service health, provisioning, plans, users/resellers,
security, mail reputation, Jobs, audit, incidents, updates, cluster and
diagnostics/repair.

## Setup UX

First-run wizard, guided/advanced modes,
detected/recommended/selected/will-change states, final review and
readiness report.

## Remaining work

Avant frontend production, convertir les contrats en information
architecture finale, route map, page inventory, component inventory,
empty/loading/error/degraded states and acceptance prototypes. Ceci est
une phase Design System/UX d'implémentation, pas une famille système
manquante.
