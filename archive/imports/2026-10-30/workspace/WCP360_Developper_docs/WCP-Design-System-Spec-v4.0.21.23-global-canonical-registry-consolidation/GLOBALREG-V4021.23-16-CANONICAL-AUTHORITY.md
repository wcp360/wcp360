# V4.0.21.23 --- Canonical Authority / Supersession Contract

Priority for implementation decisions: 1. current global
registry/ledger; 2. latest family registry V4.0.21.16--21; 3. latest
explicit deep closure/ADR for the subject; 4. historical module
specification; 5. historical audit/inventory.

A lower-priority document cannot override a higher-priority security
invariant. If two same-priority contracts conflict, implementation is
BLOCKED until an ADR or registry amendment resolves it.

Local `READY`/`IMPLEMENTATION-READY` in historical documents never
implies GLOBAL READY.
