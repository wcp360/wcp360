# V4.0.21.8 --- Render / Validate / Atomic Apply / Rollback Contract

## Universal service-config transaction

1.  resolve desired state;
2.  authorize + entitlement + compatibility;
3.  render into non-active managed artifact;
4.  static/schema validation;
5.  native service validation where applicable;
6.  snapshot active revision metadata;
7.  atomic activation;
8.  reload/restart only through closed action registry;
9.  service/endpoint health verification;
10. commit observed revision;
11. on failure: restore previous active revision, reload, verify
    rollback;
12. emit audit/job events.

## Nginx / Apache

Native config test is mandatory before activation. A failed test never
touches the active revision.

## PHP-FPM

Pool configuration is validated before reload. Runtime change verifies
binary/package availability and extension compatibility.

## DNS

Zone data is typed and validated before backend apply. Observed
serial/state is read back.

## TLS

Activation verifies private-key match, certificate chain, SAN coverage
and endpoint presentation.
