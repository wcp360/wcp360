# V4.0.21.10 --- Environment Variables, .env & Application Secrets

## Classes

`PUBLIC_CONFIG`, `SENSITIVE_CONFIG`, `SECRET`.

## Stockage

Les secrets réels résident dans SecretStore. L'UI affiche valeur masquée
et metadata ; elle ne réaffiche pas le secret après création sauf
capability explicitement conçue pour un secret exportable.

## Injection

Environment/systemd credential file/runtime file generated with strict
mode, selon adapter. Les secrets ne sont pas passés dans argv, logs, Git
commits, build artifacts publics ou audit payloads.

## `.env`

Le File Manager peut appliquer une politique spéciale aux `.env`. Une
app peut importer des clés vers SecretStore et générer un runtime
representation sans faire du `.env` le système de secrets canonique.
