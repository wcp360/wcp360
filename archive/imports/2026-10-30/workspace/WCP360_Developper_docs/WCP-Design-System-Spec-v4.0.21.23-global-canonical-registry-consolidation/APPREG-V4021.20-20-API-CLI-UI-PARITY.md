# V4.0.21.20 --- Files / Runtime API / CLI / UI Parity

WCP-ADMIN, WCP-USER, REST and CLI map to canonical Operation IDs. File
Manager, Git/deploy wizards, runtime selectors and WordPress screens are
projections of the same policy/capability/lifecycle state.

Long operations are Jobs. UI cannot invent synchronous success before
observed verification. CLI/API dry-run/impact is available for
deployment, recursive file mutation, staging clone and destructive
runtime actions where meaningful.
