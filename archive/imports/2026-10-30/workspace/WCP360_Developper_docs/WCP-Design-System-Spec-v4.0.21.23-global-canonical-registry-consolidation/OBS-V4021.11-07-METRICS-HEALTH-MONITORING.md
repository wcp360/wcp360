# V4.0.21.11 --- Metrics / Health / Monitoring Model

## Ressources

`health_check`, `health_observation`, `metric_series_ref`,
`monitor_policy`, `service_slo`, `capacity_snapshot`.

## Dimensions

Host CPU/RAM/load/disk/inodes/I/O/network, service state, HTTP endpoint
health, PHP-FPM, DB, cache, DNS, mail queues, TLS expiry, backup
freshness, scanner/signature freshness, quota pressure and control-plane
jobs.

## Health vocabulary

`HEALTHY`, `DEGRADED`, `UNHEALTHY`, `UNKNOWN`, `MAINTENANCE`.

## Readiness

Process running != service healthy. Readiness peut exiger socket,
protocol, dependency and synthetic checks.

## Cardinality/security

Metrics labels ne contiennent pas de secrets ni de données client non
bornées.
