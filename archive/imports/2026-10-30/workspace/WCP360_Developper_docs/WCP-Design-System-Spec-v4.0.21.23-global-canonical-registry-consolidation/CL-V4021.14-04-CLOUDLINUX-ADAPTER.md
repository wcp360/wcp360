# V4.0.21.14 --- CloudLinux Integration Adapter

## Principe

CloudLinux est un `IsolationProvider`/capability adapter, jamais une
dépendance obligatoire du cœur.

## Intégrations

LVE limits/usage, CageFS state, PHP Selector, Node.js Selector, Python
Selector, Ruby Selector, mod_lsapi capability, MySQL Governor mappings,
X-Ray capability and reseller/package synchronization where supported.

## Mapping

WCP account/reseller/package/domain/database-user mappings sont
explicitement exportables vers l'adapter. Les IDs CloudLinux ne
deviennent pas les IDs canoniques WCP.

## Fallback

Sans CloudLinux : cgroups v2 + systemd + filesystem quota + native
runtime registry restent utilisables selon host profile.
