# V4.0.21.14 --- Container Manager Deep Contract

## Ressources

`container_host`, `container_registry`, `container_image_ref`,
`container_app`, `container_volume`, `container_network_ref`,
`container_deployment`.

## Capabilities

pull image, create/start/stop/restart/recreate, logs, health,
env/secrets, ports, volumes, CPU/RAM/PID limits, restart policy and
image update planning.

## Security floor

Pas d'exposition du Docker/Podman socket au tenant. Privileged
containers, host PID/network, arbitrary devices, host root mounts and
unsafe capabilities sont denied by default. Rootless/restricted
execution préféré.

## Remote hosts

Optionnel, enrolled/authenticated, capability-advertised. Le host
distant n'est jamais accepté sur simple URL utilisateur.
