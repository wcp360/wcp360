# V4.0.21.14 --- Web Compatibility Utilities

Les fonctions historiques utiles sont normalisées en politiques modernes
:

-   Directory Privacy → `HTTP_ACCESS_PROTECTION`;
-   Hotlink Protection → `HOTLINK_POLICY`;
-   Index Manager → `DIRECTORY_LISTING_POLICY`;
-   Custom Error Pages → `ERROR_DOCUMENT_POLICY`;
-   MIME Types → `MIME_MAPPING_POLICY`;
-   Apache Handlers → backend-specific advanced web policy, capability
    gated;
-   IP Blocker → Security/Firewall scoped rule;
-   Raw Access Logs → Logs export;
-   web statistics → Analytics adapter.

Aucune de ces fonctions ne peut écrire directement une configuration
Apache/Nginx brute.
