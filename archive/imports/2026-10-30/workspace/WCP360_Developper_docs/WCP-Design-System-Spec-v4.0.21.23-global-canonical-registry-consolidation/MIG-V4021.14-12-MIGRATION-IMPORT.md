# V4.0.21.14 --- Migration / Import Framework

## Sources

Generic SSH/SFTP/rsync-like source adapters, archive+manifest, database
dumps, and dedicated import adapters for panels only when mappings are
certified.

## Plan

discover → inventory → compatibility → identity/domain/mail/DB mapping →
conflict plan → transfer → restore/provision → DNS cutover plan →
validation → report.

## Safety

Source credentials SecretStore-backed, no arbitrary root remote command,
dry-run mandatory for complex account migrations, checksums and
resumable transfers where supported.
