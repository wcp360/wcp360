# V4.0.21.14 --- WordPress Safe / Smart Update Pipeline

## Pipeline

checkpoint/backup → ephemeral clone → baseline crawl/tests → apply
candidate updates → post-update crawl/tests → compare → risk decision →
report → manual approval or policy decision → production update → health
→ rollback.

## Checks

HTTP status, PHP/runtime errors, critical page/title/content markers,
visual regression when screenshot engine capability exists, DB migration
result, plugin/theme/core health and synthetic flows when configured.

## Modes

`MANUAL_REVIEW`, `AUTO_IF_SAFE`, `REPORT_ONLY`.

## Rule

Safe Update complète mais ne remplace jamais Backup/Restore.
