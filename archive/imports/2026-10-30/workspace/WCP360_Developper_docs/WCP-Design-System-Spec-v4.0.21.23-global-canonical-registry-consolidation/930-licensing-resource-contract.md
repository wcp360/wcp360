# 930 --- Licensing Resource Contract

## Statut

**CANONICAL --- V3.8 CLOSURE / IMPLEMENTATION CONTRACT**

Ce document complète le corpus existant. Les règles de sécurité
`650–669` et les contrats `700–874` restent normatifs.

Ressources : `License`, `EntitlementSet`, `LicenseAssignment`,
`LicenseCheck`, `GraceState`.

Le licensing peut limiter des fonctionnalités commerciales mais ne doit
pas désactiver les mécanismes de sécurité nécessaires à l'intégrité du
système.

Validation offline/grace doit être explicitement définie par le produit
commercial avant activation. **DECISION REQUIRED** :
fournisseur/protocole de licence commercial.
