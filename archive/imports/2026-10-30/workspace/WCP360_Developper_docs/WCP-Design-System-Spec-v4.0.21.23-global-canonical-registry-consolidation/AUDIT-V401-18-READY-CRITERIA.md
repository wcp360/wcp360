# V4.0.1 --- READY Criteria

Un module READY couvre explicitement : portée/non-objectifs ;
resources/états ; lifecycle CRUD ; RBAC/tenant ; API/UI conceptuel ;
validation/limites ; dependencies/adapters/capabilities ; privileged
actions ; concurrence/locks/idempotency ; errors/failures ;
retry/reconcile/rollback ; security/abuse ; secrets ; audit ;
observability ; backup/restore ; install/upgrade/migration ; multi-OS ;
tests positifs/négatifs ; scénarios/edge cases.

Retirer `READY` si une décision obligatoire ou dépendance critique reste
ouverte.
