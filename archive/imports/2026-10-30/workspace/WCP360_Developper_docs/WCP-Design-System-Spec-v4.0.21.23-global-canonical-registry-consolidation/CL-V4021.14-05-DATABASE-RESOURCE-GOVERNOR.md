# V4.0.21.14 --- Database Resource Governor

## Objectif

Limiter et observer la consommation DB par tenant/user sans confondre
les quotas DB logiques et les limites de ressources.

## Providers

CloudLinux MySQL Governor lorsqu'il existe ; providers futurs possibles.
Le core expose `DB_RESOURCE_GOVERNOR` capability.

## Mapping

account → database → database user → governor identity. Les utilisateurs
partagés entre tenants sont interdits dans les profils qui exigent
accounting/isolation fiable.

## Observations

CPU/time, concurrent connections, slow/expensive query indicators et
provider limit events selon capacités réellement exposées.
