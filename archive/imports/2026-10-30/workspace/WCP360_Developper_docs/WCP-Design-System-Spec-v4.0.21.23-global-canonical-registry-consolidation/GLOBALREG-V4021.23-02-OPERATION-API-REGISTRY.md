## Mandatory contract columns before implementation

For every V1 operation the implementation ledger MUST additionally
resolve: actor classes, permission, scope, entitlement, capability,
lifecycle guard, step-up/confirmation, sync/Job, request schema, result
schema, stable errors, audit event, idempotency key behavior and
API/CLI/UI exposure.

An Operation ID is the canonical intent. UI labels, REST routes and CLI
commands are surfaces and MUST NOT create alternate semantics.
