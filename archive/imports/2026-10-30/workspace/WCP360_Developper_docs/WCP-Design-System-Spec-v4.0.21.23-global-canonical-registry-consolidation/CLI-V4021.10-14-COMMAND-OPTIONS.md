# V4.0.21.10 --- Files / Access / Developer CLI & Options

## Exemples

`wcpctl files upload --account <id> --root <managed-root> --path <relative>`
`wcpctl access ssh-key-add --account <id> --key-file <local>`
`wcpctl git deploy --repo <id> --ref <ref> --dry-run`
`wcpctl app install --catalog-id <id> --site <id>`
`wcpctl wordpress stage --site <id>`
`wcpctl runtime assign --app <id> --runtime <id>`
`wcpctl cron create --app <id> --schedule <typed>`
`wcpctl worker restart --worker <id>`

## Interdits

`--shell`, `--sudo`, `--root-path`, `--raw-systemd-unit`, `--raw-nginx`,
`--raw-cron-command`, arbitrary `git args`, arbitrary package manager
command executed by privileged broker.

Un fichier local passé à la CLI est uploadé/parsed par la surface
cliente puis converti en DTO contrôlé ; il n'est jamais interprété comme
chemin serveur root.
