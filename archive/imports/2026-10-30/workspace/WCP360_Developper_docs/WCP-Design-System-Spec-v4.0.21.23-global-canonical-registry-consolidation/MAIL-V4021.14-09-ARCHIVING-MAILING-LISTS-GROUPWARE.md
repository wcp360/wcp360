# V4.0.21.14 --- Mail Archiving / Mailing Lists / Optional Groupware

## Mail archiving

Policy-driven journaling/archive adapter, retention, immutable target
capability, legal/privacy constraints and tenant export.

## Mailing lists

Optional module with list/domain ownership, members, moderators, posting
policy, bounce handling and anti-abuse limits. Backend adapter required.

## Groupware

CalDAV/CardDAV/calendar/contact capability is **OPTIONAL**, not core
hosting. It has independent entitlement, storage/quota and privacy
model.
