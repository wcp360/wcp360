# V4.0.21.11 --- Backup Retention / Remote Targets / Immutability

## Targets

Local filesystem, mounted storage, object-storage compatible adapter et
autres backends certifiés.

## Capabilities

versioning, object lock/immutability, lifecycle, server-side encryption,
client-side encryption, multipart, checksum, delete protection.

## Retention

daily/weekly/monthly generations, max age, max count, storage budget,
legal hold/retention override where applicable.

## Anti-ransomware

Le compte hébergé ne possède pas les credentials permettant de supprimer
ses propres sauvegardes protégées lorsque la policy anti-ransomware
l'exige.
