# WCP360 V2.5.3.14 — STYLE LOCK

## Active visual baseline
The visual baseline is **V2.5.3.12**.

## Locked elements
- Main shell
- Header
- Sidebar
- Frame separation
- Cards and panels
- Light / Dark visual rhythm
- Typography
- Spacing
- Radius
- Shadows
- Search
- Drawers
- Job Center
- Operations Dock
- Command Center

## Rule for future migrations
Future page migrations may change only:
- content
- data structure
- page-specific components
- workflows

They must NOT replace the global shell or visual language without an explicit design decision.

## Deprecated
V2.5.3.13 Full Shell Migration is deprecated as a visual baseline because it altered the approved V2.5.3.12 style.
