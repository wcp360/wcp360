# V4.0.21.15 --- Non-functional Completeness Gate

Avant GLOBAL READY, chaque famille critique doit couvrir : security,
tenant isolation, performance limits, concurrency/idempotency,
availability/failure behavior, backup/restore, observability,
audit/privacy, upgrade/migration, accessibility/localization where
UI-facing, supportability, capacity limits, retention/deletion and
disaster recovery impact.

Les NFR ne sont pas une annexe : ils sont des critères d'acceptation.
