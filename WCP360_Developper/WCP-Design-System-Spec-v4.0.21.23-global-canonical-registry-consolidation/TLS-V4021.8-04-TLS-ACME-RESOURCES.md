# V4.0.21.8 --- TLS / ACME Resource Dictionaries

## `certificate`

`id`, `account_id`, `certificate_type`, `subject_names`, `issuer`,
`not_before`, `not_after`, `key_ref`, `chain_ref`, `status`,
`renewal_state`, `last_verified_at?`, `version`.

## `acme_account`

`id`, `provider_id`, `directory_uri_id`, `contact_refs`,
`account_key_ref`, `status`, `created_at`.

## `acme_order`

`id`, `certificate_id`, `provider_id`, `challenge_type`, `state`,
`attempt_count`, `next_retry_at?`, `created_at`, `expires_at`.

## `tls_policy`

`id`, `owner_scope`, `minimum_protocol`, `cipher_profile`,
`hsts_policy`, `ocsp_policy`, `redirect_http_to_https`,
`renewal_window`, `version`.

Private keys are SecretStore references. Certificate activation requires
key/certificate match, chain validation, hostname coverage and service
reload verification. Renewal failure must not overwrite a still-valid
active certificate.
