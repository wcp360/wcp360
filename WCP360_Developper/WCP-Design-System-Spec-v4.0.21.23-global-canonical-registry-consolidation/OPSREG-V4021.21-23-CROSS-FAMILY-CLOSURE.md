# V4.0.21.21 --- Operations Cross-Family Dependency Closure

Backup/restore spans all resource families but acts through canonical
adapters. Firewall/WAF depend on network/web and security floor. Malware
consumes managed filesystem and app context. Observability references
stable resource IDs. Updates consume Host Profile/capability registry
and affect all providers. Installer produces the initial
desired/observed baseline and Doctor proves it.

No operations subsystem is allowed to become an alternate bypass path
around RBAC, scopes, entitlements, lifecycle, Job, audit or
privileged-action contracts.
