# V4.0.21.21 --- Firewall / Network Safety Contract

Firewall is policy-driven with typed
service/port/protocol/source/destination rules and provider adapters. No
tenant raw nftables/iptables command channel.

Management-access protection performs lockout preflight. Risky changes
support temporary confirmation/automatic rollback strategy where
provider permits. Emergency access policy is platform-controlled and
audited.

Account/site scoped blocking composes with host security floor and
cannot remove mandatory management/system rules.
