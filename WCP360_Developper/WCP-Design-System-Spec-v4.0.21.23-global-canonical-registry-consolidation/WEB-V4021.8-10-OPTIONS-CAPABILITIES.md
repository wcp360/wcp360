# V4.0.21.8 --- Web Stack Options & Capability Matrix

## Webserver options

Support is capability-driven, not assumed: - Nginx only; - Apache
only; - Nginx reverse proxy to Apache; - HTTP/2 where certified; -
HTTP/3 only where backend/build/network profile supports it; - Brotli
only when module/backend certified; - gzip; - static cache policy; -
reverse proxy/upstream policy; - security headers; -
request/body/timeouts; - WebSocket proxying.

## PHP options

Multiple certified PHP versions, FPM pool modes, worker limits, per-site
safe INI overrides, extension profiles, OPcache policy and
upload/execution limits.

## TLS

ACME HTTP-01/DNS-01 according to provider capability; external/imported
certificate path may be supported by a separate governed operation. No
private-key paste into logs/audit.

## DNS

Authoritative backend is adapter-driven. RR types must be explicitly
supported by the typed registry; unknown types are not passed as raw
privileged text.

## Principle

UI displays only options actually available on the selected host/backend
and explains `UNAVAILABLE` instead of silently ignoring a setting.
