# 1093 --- Definition of Done

## Statut

**CANONICAL --- DEVELOPER BLUEPRINT --- V3.9**

Ce document traduit les contrats `IMPLEMENTATION-READY` V3.8 en
organisation de code et ordre de construction. Il ne modifie pas les
décisions normatives de sécurité `650–669`.

Une capability V1 est Done si : contract doc lié, resource/API/RBAC
définis, migration si nécessaire, audit, job/event, adapter capability,
validation/limits, negative security tests, cross-tenant tests,
observability, docs opérateur, upgrade/recovery behavior et acceptance
tests verts.

Une page UI seule n'est jamais une feature Done.
