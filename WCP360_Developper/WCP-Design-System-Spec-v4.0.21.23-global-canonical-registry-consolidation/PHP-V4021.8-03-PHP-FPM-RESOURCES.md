# V4.0.21.8 --- PHP / PHP-FPM Resource Dictionaries

## `php_runtime`

`id`, `version`, `sapi`, `package_source`, `support_state`,
`capabilities`, `installed_state`, `observed_at`.

## `php_profile`

`id`, `owner_scope`, `runtime_id`, `ini_policy`, `extension_set_id`,
`fpm_policy`, `security_policy`, `version`.

## `php_pool`

`id`, `site_id`, `account_id`, `runtime_id`, `unix_identity_ref`,
`socket_ref`, `pm_mode`, `worker_limits`, `request_limits`, `status`,
`desired_revision`, `observed_revision?`, `version`.

## `php_extension_set`

`id`, `owner_scope`, `runtime_id`, `extensions`, `policy_state`,
`version`.

## `php_ini_override`

`id`, `site_id`, `key`, `typed_value`, `source_scope`, `security_class`,
`validation_state`, `version`.

## Rules

PHP version selection is constrained by installed/certified runtimes.
Dangerous INI keys and extension changes are governed by security
floors. Pools run under the site's managed identity and isolation
assignment. Socket paths are generated, not user-controlled.
