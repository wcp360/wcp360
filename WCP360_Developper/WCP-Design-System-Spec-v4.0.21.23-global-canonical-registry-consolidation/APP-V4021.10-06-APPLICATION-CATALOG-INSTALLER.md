# V4.0.21.10 --- Application Catalog / Installer Deep Contract

## Catalogue

Chaque application/version possède manifest signé ou approuvé, source,
checksums, compatibilités runtime/DB/PHP/extensions, besoins stockage,
post-install schema, health check et upgrade path.

## Applications candidates

WordPress, Nextcloud, PrestaShop, Magento/OpenSearch-dependent profiles,
Laravel starter, Ghost et templates Node/Python peuvent être proposés
seulement si leurs dépendances sont certifiées par le host profile.

## Installation

Preflight → dependency resolution → resource reservation → source
verification → database/credential creation → files → config/secrets →
runtime/web config → install action → health → commit.

## Supply chain

Checksum/signature/source provenance obligatoire selon classe. Pas de
téléchargement arbitraire exécuté root depuis une URL fournie par le
client.
