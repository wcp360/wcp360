## Ownership rule

This extraction consolidates explicit lower-snake identifiers present in
the canonical-family corpus. `First owner candidate` is an audit aid,
not automatic normative ownership. Final owner is the most specific
canonical family contract.

Every implementation resource MUST have: stable ID, tenant/host
ownership, lifecycle, sensitivity, persistence authority and
delete/retention semantics.
