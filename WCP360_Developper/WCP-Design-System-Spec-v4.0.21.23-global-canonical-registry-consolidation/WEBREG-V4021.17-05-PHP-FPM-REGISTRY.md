# V4.0.21.17 --- PHP / PHP-FPM Registry

## Resources

Runtime version capability, site runtime assignment, FPM pool and typed
PHP settings.

## Operations

`PHP-VERSION-ASSIGN`, `PHP-SETTINGS-UPDATE`, `PHP-FPM-POOL-RECONCILE`,
`PHP-FPM-RESTART`, `PHP-RUNTIME-CAPABILITY-READ`.

## Isolation

Pool identity derives from hosting account/system identity. Socket paths
are generated by WCP, not user supplied. CPU/RAM/process ceilings are
constrained by account isolation/plan. `disable_functions`-like controls
are not treated as an OS isolation boundary.

Unsupported runtime versions produce `CAPABILITY_UNAVAILABLE`, never
implicit package installation outside the update/package policy.
