# V4.0.21.11 --- Operations / Installer CLI Surface

Exemples : `wcpctl backup run --account <id>`
`wcpctl backup verify --artifact <id>`
`wcpctl restore plan --artifact <id> --target <id>`
`wcpctl security scan --account <id>` `wcpctl firewall rules`
`wcpctl monitor health` `wcpctl logs query --scope <id>`
`wcpctl update plan` `wcpctl doctor run` `wcp-installer preflight`
`wcp-installer status` `wcp-installer resume` `wcp-installer finalize`
`wcp-installer verify`

`wcp-installer` reste séparé du runtime normal et ne devient pas un
shell root.
