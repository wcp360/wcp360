# Core application source

Use App namespaces and injected services. Business modules belong under Module; stable cross-cutting code belongs under Shared. Controllers/forms/presenters remain thin and domain operations stay authorized.

This is an implementation reservation. Follow the [Core status](../README.md) and [development/acceptance guide](../../documentation/development/CORE-ENGINE.md) before adding runtime code.

Find the concrete owner in the [module index](Module/README.md) or use the [Core change-location index](../NAVIGATION.md) to locate commands, configuration, dependencies and templates.
