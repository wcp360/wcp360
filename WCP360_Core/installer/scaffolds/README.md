# Historical installer scaffolds

The v1.0.0 and v1.1.0 folders were moved here from WCP360_Release. They are guarded Bash development templates, not qualified versions.

- [v1.0.0 guide](v1.0.0/README-INSTALL.md)
- [v1.1.0 guide](v1.1.0/README-INSTALL.md)

Both scripts retain their original bytes and executable modes. Help/version output is available; default and --check exit 78 without installing or changing the system. No production archive or daemon binary is provided.

There is no latest alias here or in WCP360_Releases until a real stable release is qualified. See [delivery and release acceptance](../../../documentation/development/DELIVERY-AND-RELEASES.md).
