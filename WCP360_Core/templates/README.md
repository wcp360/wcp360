# Core Twig templates

First-party Symfony/Twig presentations. admin and user remain separate request/security contexts; components are reusable UI, and setup contains the restricted wizard. Detached plugin Twig files are never added to the Core loader.

This is an implementation reservation. Follow the [Core status](../README.md) and [development/acceptance guide](../../documentation/development/CORE-ENGINE.md) before adding runtime code.
