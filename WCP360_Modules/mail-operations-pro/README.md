## Proposed optional scope

Advanced mail portfolio workflows for provider-assisted mailbox moves, coordinated domain cutovers, optional collaboration-suite integration and large-group policy campaigns. Compatibility is qualified for each source, destination and selected connector.

## Retained Core boundary

All eighteen essential mail capabilities, including domains, mailboxes, quotas, queues, signing, baseline protection and diagnostics, remain Core responsibilities. This module adds optional migration and collaboration orchestration without replacing mail identity or routing policy.

PRO entitlement is separate from package trust/compatibility and current Core permissions. Hosted services and independent Core control/recovery must survive expiry, provider failure, disablement and removal.
