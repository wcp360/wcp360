## Proposed optional scope

Advanced customer-application test campaigns using isolated preview environments, version matrices, synthetic user journeys and comparison before promotion. Reports separate installability, compatibility, security checks and measured performance.

## Retained Core boundary

Core's own tests, quality tools and essential hosted-resource checks remain freely available. This module adds optional application-specific rehearsals; it does not certify applications, imply upstream support or treat passing syntax as runtime compatibility.

PRO entitlement is separate from package trust/compatibility and current Core permissions. Hosted services and independent Core control/recovery must survive expiry, provider failure, disablement and removal.
