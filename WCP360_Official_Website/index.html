Essential answers

Understand the product before trusting it.

Short answers to the questions operators should ask before evaluating a hosting control plane.

Read technical documentation
Is WCP360 a replacement for cPanel / WHM?

That is the product direction: a modern open-source control system covering hosting accounts, websites, DNS, mail, databases, files and server governance. The current build is still a functional design prototype, not a production replacement.

Does the platform work without plugins?

The public core is designed to retain authentication, account ownership, hosting baseline, jobs, audit and recovery when every optional extension is disabled. Extensions add capabilities; they do not secretly complete the core.

How are ROOT, reseller and user kept separate?

They are authorization scopes, not themes. The API evaluates actor, capability, tenant and resource ownership on the server. A visual switch can demonstrate interfaces, but it cannot grant production privileges.

Does a customer installation depend on WCP360 private infrastructure?

No private service should be required for the public product to continue operating. License, catalog, update and consented insights clients must fail safely, cache only approved state and expose their connectivity clearly.

What is open source and what can have another license?

The stated target is an MIT-licensed public core. Official or third-party extensions can declare their own compatible license and edition requirements before installation. Private vendor control systems are developed and distributed separately.

Can I install WCP360 on a production server today?

No. The official website labels installer endpoints as prototype examples. Use the Installation Center to understand requirements and the intended verification process, then follow the roadmap for signed release availability.
