Responsibility model

ROOT defines the envelope. Users deploy inside it.

The same installer presents different controls to ROOT, reseller and hosting users. Capabilities never leak between scopes.

ROOT

Platform governance

Controls whether the extension exists and what it may do across the platform.

  • Enable globally, per server, plan or account
  • Approve publishers, recipes and versions
  • Define runtimes, quotas and network policy
  • Require backup, scan and maintenance windows
Owns platform policy
RESELLER

Delegated catalogue

Curates an allowed subset without escaping the ROOT resource and security envelope.

  • Expose approved apps to assigned plans
  • Set defaults within delegated limits
  • Review customer installs and consumption
  • Cannot add publishers or widen permissions
Owns delegated offers
USER

Application lifecycle

Selects a permitted app and manages it inside the assigned hosting account.

  • Choose domain, path and safe configuration
  • Install, update, clone, stage or rollback
  • View health, logs and generated credentials
  • Cannot change global runtime or security policy
Owns application intent

Full application lifecycle

Installation is only the first operation.

Each operation reuses the same policy, backup, health and audit controls as the initial install.

01Install

Preflight, checkpoint, provision, verify.

02Update

Compatibility diff, backup and health gate.

03Clone

New identity, secrets, database and URL rewrite.

04Stage

Isolated preview with promotion evidence.

05Rollback

Restore files, data and runtime atomically.

06Uninstall

Export, retain or reviewed data deletion.

UPDATES

Compatibility before change

Core, plugin, theme, runtime and database requirements are diffed before scheduling.

BACKUP

Application-consistent restore points

Maintenance hooks coordinate files, database, queues and caches before the checkpoint.

HEALTH

Post-install acceptance gates

HTTP, database, queue, cron, SSL and application checks decide whether to commit or roll back.

SECRETS

Generated, scoped and rotatable

Database and application credentials never reuse the hosting account password.

Extension boundary

Detachable by design.

If Application Installer is disabled or unhealthy, its catalogue, jobs and routes withdraw cleanly. Existing applications continue to run and remain manageable through websites, files, databases, backups and runtime tools.
