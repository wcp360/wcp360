Security by architecture

Privilege is temporary.
Evidence is durable.

WCP360 is designed around least privilege, closed node operations, explicit trust boundaries and recoverability. This page describes the target security model; disclosure channels and GPG keys are not published yet.

Security properties

Controls that must remain true.

IDENTITY

No universal panel root

Customer ROOT, vendor workforce and Linux accounts are separate identities with separate policy and audit.

EXECUTION

No arbitrary extension shell

The node agent exposes versioned closed operations over mTLS; extensions receive scoped tokens only.

CONTINUITY

No destructive licensing

License status cannot delete data, stop healthy workloads or block login, export, backup and recovery.

SUPPLY CHAIN

No exclusion-only build

Public archives use a positive component allowlist, locked sources, SBOM, provenance and signatures.

SUPPORT

No hidden remote access

Support requires customer consent, exact purpose, scope, time limit and immutable session evidence.

EXTENSIONS

No silent capability growth

Permission changes require review, canary activation and a rollback slot before new access takes effect.

Release assurance

Trust the artifact, not the download page.

Each stable package is intended to carry evidence that can be verified independently before installation.

ChecksumsVersioned SHA-256 digest and detached signature.
SBOMCycloneDX components, versions and licenses.
ProvenanceCommit, dependency locks, runner digest and builder identity.
RevocationSigned artifact-hash revocation without remote workload shutdown.
RecoveryPreflight, staged activation, health gates and last-known-good rollback.

Detached Insights Connector

Diagnostics require consent.

The optional connector is a separate signed extension, excluded from public core builds and disabled by default.

01
Outbound only

Pinned mTLS connection; no inbound listener or hidden command channel.

02
Purpose-limited scopes

Inventory, health, extension failure and reviewed bug context are enabled independently.

03
Forbidden content

No hosted files, messages, database rows, credentials or raw customer content.

Responsible disclosure

Disclosure channel pending publication.

Do not send a vulnerability to the reserved preview address shown in prototype documentation. Before public launch, WCP360 will publish a monitored security address, scope, response targets, encryption key and coordinated disclosure policy.

GPG status

No project GPG fingerprint is published by this prototype. Any key or package claiming otherwise must be treated as untrusted.
