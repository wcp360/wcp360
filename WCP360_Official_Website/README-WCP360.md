# WCP360 Official Website

This directory now contains the static, responsive WCP360 product website.

## Active pages

- index.html — homepage
- features.html — complete capability map
- plugins.html — official extensions and marketplace prototype
- about.html — mission, audiences and principles
- forum.html — community experience mockup
- docs.html — technical documentation preview
- roadmap.html, editions.html, status.html, security.html, legal.html

Shared UI lives in assets/wcp360-site.css and assets/wcp360-site.js.

## Prototype placeholders

The wcp360.example origin is deliberately reserved and is not a live installer or production domain. Replace it only after a production origin, signed packages and disclosure channels exist.

Older NETTOYAGE 360 pages and media were left untouched as orphaned legacy content. They are not linked by the WCP360 navigation or sitemap and can be archived separately after explicit approval.
