Current program

Four delivery tracks.

Tracks can progress independently, but stable promotion requires their contracts to converge.

TRACK A · CURRENT

Product architecture

Consolidate ROOT, reseller and user ownership; complete system settings, extension boundaries and end-to-end lifecycle states.

TRACK B · NEXT

Production core

Identity, API, jobs, audit, node agent, accounts, hosting services, installer, updates and local recovery baseline.

TRACK C · PLANNED

Official extensions

Application Installer, pipelines, remote connectors, HA/DR and forensics through the conformance-tested SDK.

TRACK D · PLANNED

Stable ecosystem

Signed public releases, publisher review, documentation, support policy and community governance.

QUALITY GATE

Security & recovery

Threat models, migration tests, crash behavior, rollback, backup verification and immutable operational evidence.

RELEASE GATE

Reproducible delivery

Positive allowlist, locked dependencies, SBOM, provenance, signatures, staged rollout and tested rollback target.
