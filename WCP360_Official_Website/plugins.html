Failure isolation

Disabled means detached — not broken.

Extensions never become hidden requirements for authentication, account ownership or the hosting baseline. If one stops, its routes withdraw, its jobs drain and the declared core fallback takes over.

Marketplace assurance

Install is a security decision.

WCP-ADMIN shows who published an extension, what it can do, which data it owns and how the system behaves without it.

Publisher trustIdentity verification, signing certificate, revocation status and distribution channel.
CompatibilityExact core range, dependencies, conflicts, migration dry run and rollback slot.
Permission diffAdded, removed or expanded capabilities require explicit ROOT review before activation.
Runtime healthLatency, error budget, crash loop and circuit-breaker state determine whether routes remain published.
Uninstall policyActive-job drain plus export, retain or reviewed deletion of extension-owned data.

For extension authors

Build once. Declare everything.

Start with a versioned manifest, narrow capabilities and conformance tests that prove the core keeps working through crash, upgrade, disable and uninstall.
